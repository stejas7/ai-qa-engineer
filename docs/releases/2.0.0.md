# Auravis 2.0.0 — Autonomous AI UAT Engineer

## Product reset

Auravis 2.0.0 centers the product around one autonomous UAT mission rather than a collection of manually operated version pages.

> Give Auravis an end-to-end business requirement and a UAT environment. Auravis automatically moves from requirement understanding to test design, automation generation, UAT execution, failure diagnosis and a final quality decision.

## Core capabilities inside one mission

1. **Requirement intelligence**
   - Business requirement analysis
   - Business rules
   - Acceptance/test scenarios
   - AI provider with deterministic fallback

2. **Intelligent test design**
   - Functional coverage
   - Negative coverage
   - Boundary coverage
   - Traceability coverage

3. **Automation generation**
   - Playwright Java test artifact generation
   - UAT URL and generated test metadata

4. **UAT execution**
   - Playwright execution
   - Supported browser actions
   - PASS/FAIL result
   - Screenshot evidence

5. **Failure intelligence**
   - Automatic failure classification
   - Severity
   - Probable cause
   - Recommendation
   - Retry signal

## Important boundary

Auravis uses AI for reasoning where appropriate, while browser execution remains deterministic and controlled through Java services and Playwright. Unsupported actions fail explicitly rather than being guessed.
